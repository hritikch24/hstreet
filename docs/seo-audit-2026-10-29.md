# High Street Shopfronts SEO implementation — 29 October 2026

Scope: the current source tree and read-only checks of https://www.highstreetshopfronts.co.uk. Existing uncommitted changes were retained. Nothing was staged, committed, pushed, deployed, or submitted to a search engine. This is a reviewable local implementation, not a claim that Google has indexed the changes.

Method: the requested [claude-seo skill](https://github.com/AgriciDaniel/claude-seo), installed under `~/.claude/skills/seo`, including its technical, sitemap, schema, and agentic checks. Its runtime doctor reported Python ready and bundled Chromium unavailable. Browser checks instead used the already-installed Playwright package with local Google Chrome. No dependencies were installed.

## Search intent, content and trust

The current architecture separates purchase decisions from urgent repair help. That separation should guide future copy and Search Console reviews:

| Visitor need | Main landing page | Supporting evidence or next step |
| --- | --- | --- |
| Price and specify an aluminium frontage | `/aluminium-shopfronts` | Real work photos, `/prices`, measurement guide and photo quote form |
| Compare manual and electric shutters | `/roller-shutters` | Existing comparison guide and the relevant guide-price bands |
| Find help for a jammed shutter | `/shutter-repairs` | Safe checks guide, actual repair coverage and the confirmed emergency phone |
| Check what can be repaired nearby | `/repairs`, existing repair-area pages | The confirmed radius and genuinely relevant local access details |
| Arrange fitting outside Birmingham | `/nationwide`, existing install-city pages | How surveys, travel and fitting are handled; confirmed job evidence when available |
| Establish who is quoting and how to contact them | `/the-firm`, `/talk-to-us` | Registered company disclosure, consistent phone/email/hours, own-work photographs and privacy notice |

Existing guide content is answer-first and resolves actual pre-purchase or safety questions. The new index makes that collection easier to navigate without publishing speculative articles. The existing pages already have distinct service, repair and installation intent; no service-by-city matrix or competing near-duplicate pages was introduced. Keyword demand, current ranking and competitors' backlink strength were not measured, so the table is an intent map, not a claimed search-volume study.

The most useful future content depends on new business evidence:

1. An approved completed frontage job: what the owner needed, constraints found at survey, specification agreed, fitting sequence, genuine before/after photographs and the actual town/month. Link it from the matching service and relevant location page; do not publish guessed client details or project costs.
2. A documented repair: reported symptom, safe initial advice, what the fitter actually found, parts replaced and outcome. Name a response time or total cost only if the job record supports it. Link from the repair service and relevant area page.
3. A written shutter-specification decision: explain a real customer's manual/electric and lath-choice tradeoff, using the supplied specification and its maintenance requirements. Keep it separate from the existing generic comparison guide by supplying real project evidence.

A named author biography would add useful accountability only if the owner provides a real person, role, relevant experience and permission to publish. The site currently presents the firm collectively, so its visible byline and Article author use the company. Social profile IDs, professional registrations, warranties, reviews and trade memberships remain absent until independently verifiable. There is no legal or ranking benefit to inventing them.
